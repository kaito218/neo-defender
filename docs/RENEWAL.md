# リニューアル設計・作業記録

## 現状分析
- React 19 / TypeScript / Vite 6。Canvas 2D、600×800、フレーム依存の縦スクロール。
- App.tsx内でrequestAnimationFrame・矩形衝突・入力・射撃・敵・UIを管理。頻繁なReact state変更でループが再生成される構造。
- TWIN / SPREAD / LASER / HOMING、ボム・ダッシュ・スロー・ハイパー・回復・バリア・ドローンを実装済み。
- スコア閾値でステージ更新・ボス生成。独立したステージデータやクリア進行なし。
- localStorageはhighScoreのみ。既存値を新セーブへ移行する。
- GitHub Actions: main push → npm ci → npm run build → Pages。Vite base './'を維持。
- 作業前git statusはクリーン、元コミット f9e66a2。旧src/public/設定は作業タスクのwork/neo-defender-backupにコピー済み。

## 段階的改修
1. 型・データ・保存・共通入力を独立したモジュールに追加。旧ゲームはこの段階で維持。
2. 固定1280×720 Canvas、時間ベースのゲームループ、横移動、各入力を実装。
3. 機体5種、敵種、武器倍率、ボス3フェーズ、描画を実装。
4. データ駆動の7ステージ、2つの分岐、仲間、進行保存・解放・エンディングを接続。
5. 無限スコアアタック、音、タイトル・ハンガー・設定・ポーズ・結果を接続。
6. ビルド・静的チェック・ロジックテスト・利用可能なブラウザで検証。

## 再利用方針
既存の4武器とアイテムの名称、追尾の加速ベクトル、矩形当たり判定、星の多層パララックス、パーティクル方式、ボム弾消し、無敵時間、スロー/ハイパー資源、Pages設定を引き継ぐ。速度・タイマーを秒単位にし、React表示更新を10Hzへ制限する。
