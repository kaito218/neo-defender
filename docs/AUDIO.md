# Original soundtrack

All six BGM tracks are original procedural compositions generated by
`scripts/create-music.mjs`. No external recordings or samples are used.
Regenerate with `node scripts/create-music.mjs` from the project root.
The checked-in WAV files are ready to ship; generation is not needed at build time.

| Scene | Title | BPM |
| --- | --- | --- |
| Title / hangar | NEON HORIZON | 112 |
| Stage | AFTERBURNER | 138 |
| Boss | IRON PULSE | 156 |
| Final boss | BREAK THE CHOIR | 164 |
| Score attack | OVERCLOCK | 148 |
| Ending | HOMEWARD LIGHT | 96 |

Stereo PCM WAV, 22.05 kHz, 16 bit, looped. A single audio element loads the current
track. Effects use bounded Web Audio voices with synthesized oscillators/noise.
Tap any menu button to enable audio; use the title sound button or settings sound
check to try playback. Settings retain separate music and effects volume controls.
